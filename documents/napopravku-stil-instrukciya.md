# Основной стиль НаПоправку

Пакет для тех, кто делает макеты, тексты и картинки в фирменном стиле — сам или с помощью нейросети. Внутри: логотипы, правила по шрифту и цветам, готовый промт.

## Что внутри пакета

```
Инструкция.md   этот файл
Промт.md        готовый промт для нейросети
Цвета.md        все цвета с кодами: HEX, RGB, CMYK, Pantone, RAL
logos/          шесть допустимых версий логотипа
```

## Логотип

**Какую версию брать.** Выбор зависит от фона:

| Фон | Файл |
|---|---|
| Светлый | `logo-osnovnoy.webp` |
| Светлый, одноцветная печать | `logo-na-svetlom-monohrom.svg` |
| Тёмный | `logo-na-temnom.svg` |
| Тёмный, одноцветная печать | `logo-na-temnom-monohrom.svg` |
| Узкое место по ширине | `logo-vertikalnyy.png` |
| Аватар, иконка, фавикон | `znak.png` |

**Охранное поле.** Со всех сторон от логотипа оставляем свободное место, равное ширине и высоте буквы Н в знаке. Внутрь этого поля не заходят ни текст, ни другие объекты, ни край макета.

**Сложные фоны.** Если фон пёстрый, тёмный, градиентный или это фотография — логотип ставится на белую плашку со скруглёнными углами. Отступ от края плашки до знака — не меньше половины высоты знака, радиус скругления пропорционален отступу.

**Знак отдельно.** Знак без квадратной подложки используется только там, где подложка мешает: аватар в соцсетях, иконка приложения, фавикон.

**Чего не делаем:**

- не перекрашиваем в нефирменные цвета;
- не растягиваем и не сжимаем — только пропорциональное масштабирование;
- не поворачиваем под углом;
- не добавляем тени, обводки и свечение;
- не обесцвечиваем в серый;
- не ставим на фон без контраста и на текстуры без плашки.

## Шрифт

Только **Montserrat**. Скачать: `fonts.google.com/specimen/Montserrat`. Нужны три начертания — Regular, SemiBold и Bold.

Три уровня текста:

| Уровень | Начертание | Интерлиньяж |
|---|---|---|
| Крупный заголовок | Bold | 100% |
| Средний подзаголовок | SemiBold | 120% |
| Основной текст | Regular | 160% |

Чем мельче текст, тем больше межстрочное расстояние — так он читается легче.

**Цвет текста** — не чёрный, а тёмно-синий `#373660`. Дальше по убыванию контраста: `#5E5E80` для вторичного текста, `#8686A0` для подписей, `#D7D7DF` для разделителей. Белый — только на тёмных подложках.

## Цвета

Основная пара бренда — оранжевый `#FFB401` и голубой `#00B9D1`. В телемед-направлении голубой заменяется фиолетовым `#8037FC`, оранжевый остаётся общим.

Насыщенные оттенки идут в акценты и кнопки, светлые — в фоны и подложки. Полный список с кодами для печати — в файле `Цвета.md`.

## Как работать с нейросетью

1. Приложите к чату `Промт.md` и, если нужен логотип, файл из папки `logos`.
2. Вставьте промт и допишите задачу: что делаем, для кого, какой формат.
3. Проверьте результат по трём пунктам: шрифт Montserrat, цвета из палитры, логотип не искажён.

Нейросеть не гарантирует точное попадание в цвет — итог всегда сверяйте с гайдлайном: `napopravku-guide.netlify.app`.
