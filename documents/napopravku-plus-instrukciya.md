# Как пользоваться этим набором в ИИ-инструментах

Набор самодостаточный: в нём лежат правила бренда, CSS-токены, логотипы, иконки, фото и готовый шаблон презентации. Ничего скачивать дополнительно не нужно.

## Что внутри

| Файл | Зачем |
|---|---|
| `BRAND-PROMPT.md` | Короткая выжимка бренда со всеми токенами. **Это главный файл — с него начинайте.** |
| `README.md` | Полный бренд-гайд: тон голоса, визуальные основы, иконография, типографические правила, состав компонентов. |
| `SKILL.md` | Файл навыка для Claude Code / Agent Skills. |
| `styles.css` + `tokens/*.css` | Цвета, типографика, отступы, тени, радиусы в CSS-переменных. |
| `Brandbook.html` | Брендбук — открывается в браузере, печатается в PDF. |
| `templates/presentation/НаПоправку-Плюс-шаблон.pptx` | **Шаблон для Google Slides / PowerPoint** — 31 слайд, редактируемый текст. Основной рабочий файл. |
| `templates/presentation/Presentation.html` | Тот же шаблон в HTML — эталон стиля и источник для правок в браузере. |
| `assets/logo/` | Логотип: `logotype-main.svg` (основной), `logotype-dark.svg` (тёмный), `logo-mark.svg` (только знак). |
| `assets/icons/`, `assets/icons-custom/` | Иконки в виде JS-данных (имя → SVG). |
| `assets/photos/` | Фотографии для полноэкранных слайдов. |

## ChatGPT / Claude / Gemini (веб-чат)

1. Загрузите в чат `BRAND-PROMPT.md` и `styles.css`. Если задача про презентацию — добавьте `templates/presentation/Presentation.html`.
2. Напишите так:

> Ниже — бренд-гайд и CSS-токены компании НаПоправку Плюс. Используй **только** эти цвета, шрифт и правила. Основные акценты — оранжевый #FFB401 и голубой #00B9D2; фиолетовый и зелёный второстепенные. Шрифт Montserrat. Не придумывай новых цветов, градиентов и логотипов.
> Сделай <что нужно>. Отдай одним HTML-файлом.

3. Для слайдов добавьте:

> Возьми структуру и стили из приложенного Presentation.html: слайд — `<section>` 1280×720, поля 64px сверху / 80px по бокам, заголовок 44px #373660, подвал с названием презентации и номером страницы. Сохрани сетку и типографику, поменяй только содержание.

**Обязательно напомните про типографику** (иначе ИИ забудет):

> В русском тексте ставь неразрывные пробелы после коротких предлогов и союзов, между числом и единицей (1 млн, 480 тыс., 35 ₽) и перед тире.

## Claude Code / Cursor / другие агенты в IDE

1. Положите папку набора в проект — например `.claude/skills/napravku-plus-design/` (для Claude Code) или просто `design/` (для Cursor).
2. В Claude Code навык подхватится сам благодаря `SKILL.md`. Вызов: `/napravku-plus-design`.
3. В Cursor добавьте в `.cursorrules`:

```
При любой вёрстке интерфейсов и презентаций читай design/README.md и design/styles.css
и используй только оттуда цвета, шрифты, отступы и радиусы.
Основные акценты — #FFB401 и #00B9D2. Шрифт Montserrat. Логотипы бери из design/assets/logo/.
Свои SVG-логотипы не рисуй.
```

## Google Slides — основной сценарий

В наборе лежит готовый файл **`templates/presentation/НаПоправку-Плюс-шаблон.pptx`** — все 31 слайд редактируемыми текстом и фигурами, не картинками.

**Импорт:**
1. Google Slides → **Файл → Открыть → Загрузка** → выберите `.pptx`. (Или загрузите файл на Google Диск и откройте двойным кликом.)
2. **Файл → Настройки страницы → Widescreen 16:9** — проверьте, что стоит именно этот формат.
3. Шрифт: **Montserrat** есть в Google Slides. Если подставился другой — выделите всё (Ctrl+A) и выберите Montserrat через «Другие шрифты».

**Как работать дальше:**
- Слайды-разделители, титул и финал уже в фирменных цветах — меняйте только текст.
- Чтобы добавить слайд в стиле шаблона: правый клик по нужному слайду → **Дублировать слайд**, затем замените содержание. Не создавайте пустой слайд из стандартных макетов — он придёт с чужой типографикой.
- Логотип в шаблоне — картинка. Если нужно вставить заново: **Вставка → Изображение** и файл из `assets/logo/`. На фото логотип всегда на белой подложке.
- Номер страницы и название презентации в подвале — обычные текстовые блоки, правятся вручную (Google Slides не подставляет их автоматически). Чтобы менять название один раз для всех слайдов, вынесите подвал в **Вид → Тема → Мастер-слайд**.

**Что может поехать при импорте (проверьте эти слайды):**
- Градиентные фоны на титуле и разделителях Google Slides поддерживает, но может слегка изменить угол.
- Графики и диаграммы собраны из прямоугольников — они импортируются как фигуры и остаются редактируемыми, но не как «живые» диаграммы Google Slides. Если нужны настоящие графики с данными — вставьте диаграмму из Google Sheets и покрасьте её в #FFB401 / #00B9D2.
- Неразрывные пробелы сохраняются. Если правите текст в Slides, ставьте их сочетанием **Ctrl+Shift+Space** (Windows) / **Option+Space** (Mac).

**Если просите ИИ сделать слайды для Google Slides:**

> Сделай презентацию по бренд-гайду во вложении. Отдай в формате, который импортируется в Google Slides: размер слайда 1280×720 (16:9), шрифт Montserrat, текст — настоящими текстовыми блоками, а не картинками. Цвета только из палитры: #FFB401, #00B9D2 — основные; #373660 — текст; #FFF8E6 и #E6F8FB — светлые подложки. Не используй сине-фиолетовые градиенты.

## Как править шаблон презентации

Открывается двойным кликом в браузере — сборка не нужна. Один слайд — один `<section data-screen-label="N">`. Чтобы добавить слайд, скопируйте ближайший по смыслу `<section>` целиком и замените текст. Номер страницы лежит в `<span data-page-num>`.

Печать в PDF: Ctrl/Cmd+P → «Сохранить как PDF», поля «Нет», фоновая графика включена.

---

## Что нельзя делать

- Рисовать или перерисовывать логотип — только файлы из `assets/logo/`.
- Вводить цвета вне палитры, особенно сине-фиолетовые градиенты.
- Ставить текст мельче 15px на слайде 1280×720.
- Класть логотип на фото без белой подложки.
- Менять шрифт: только Montserrat (подключается с Google Fonts, лицензия OFL).
